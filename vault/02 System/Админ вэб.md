# Админ вэб

> Компанийн дотоод vault-ын есөн тэмдэглэлийг дипломд зориулж нэгтгэсэн, улсын дугаар, хүний нэр, хар жагсаалтын агуулга, дотоод холбоосыг хассан хувилбар ([[Эх сурвалжийн зураглал]]).

## Тойм
- Хаяг: `https://admin.opendevelopment.mn`. Repo `opendev_admin`, `main` = live, Vercel өөрөө build хийнэ; буцаах = merge-ийг revert.
- Stack: Next.js App Router, shadcn/ui + Tailwind, REST API + Socket.IO (live мэдэгдэл). Газрын зураг OpenStreetMap (Leaflet), түлхүүр шаардлагагүй.
- Хэл: Монгол (үндсэн), English, 中文. Код Монголоор, `lib/i18n/en.json`, `zh.json` текст бүрийг орчуулна; дутуу орчуулгыг скриптээр шалгана.
- Загвар: flat (сүүдэр, градиент, пастел pill байхгүй), өнгө зөвхөн утгатай газар (ногоон хэвийн, улбар анхаар, улаан зогс). 2026-10-27-оос аппын 2.0 загвартай ижил: нүүрсэн хар цэс `#17181A`, идэвхтэй хуудас шар `#F2C200`, дэвсгэр `#F4F4F1`, IBM Plex Sans + Plex Mono (улсын дугаар, литр), Open Teever хаалганы тэмдэг.
- Компани өөрөө бүртгүүлэх `/register` хуудас хасагдсан: байгууллагыг superadmin үүсгэнэ.

## Цэс ба хуудас
Цэс ажлын төрлөөр бүлэглэгдсэн (2026-10-20), бүлэг бүр хаалттай эхэлж, нээсэн хуудасны бүлэг өөрөө нээгдэнэ (2026-10-27). Дээд хайлт цэсний бүх хуудсыг нэр, тайлбар, бүлгээр олно. Жагсаалт `lib/nav.ts`-д.

| Бүлэг | Хуудас |
|---|---|
| Нүүр | `/` хяналтын самбар: энгийн үг, тоо, "Анхаарах зүйлс" мөр дээр дарахад хуудас нээгдэнэ |
| Тээвэр | `/tasks`, `/tasks/new`, `/tasks/[id]` (рейс), `/dispatch` (ажлын самбар), `/requests`, Газрууд |
| Жолооч | `/drivers`, `/drivers/[id]`, `/drivers/blacklist`, `/drivers/requests/[id]`, `/owner-operators` (хувийн тээвэрчин) |
| Түлш | `/fuel` (түлшний баримт, GPS цэнэглэлт), "GPS түлшний хяналт" цэс нь түлшний хяналтын сайтыг нээнэ |
| Машин ба засвар | `/vehicles`, `/vehicles/[id]`, `/vehicles/gps`, `/vehicles/import` (Excel), `/vehicles/requests`; `/repairs`, `/repairs/components`, `/repairs/acts`, `/inspections` (Үзлэг / Хүлээлцэх акт), `/print/component-act/[id]` |
| Газрын зураг | `/tracking`, `/tracking/[driverId]`, `/tracking/trips/[id]` (өмнө "Хяналт" гэдэг байсан) |
| Удирдлага | `/reports`, `/notifications`, `/announcements` |
| Тохиргоо | `/organization` (2 tab), `/settings/users` (хэрэглэгч ба эрх), `/settings`, `/settings/audit`, `/organizations` (superadmin) |
| Нийтийн | `/track`, `/track/[code]` (нэвтрэлтгүй ачаа хянах), `/login`, `/forgot-password` |

Хасагдсан хуудсууд: ХУР-аар машин шалгах, Харилцагч, интеграцын тохиргоо, ХУР/ДАН хүсэлтийн лог (2026-10-19; API ба өгөгдөл хэвээр); "Бүрдэл" хуудас `/rigs` (2026-10-27; өгөгдөл хэвээр, бүрдэл машин ба засварын хуудсанд бичгээр харагдана; бүрдэл үүсгэх/хаах боломж үүнтэй хамт алга болсон); "GPS төхөөрөмж" цэс (трекерийг машины хуудасны "Дотоод мэдээлэл" картаас холбоно).

## Эрх ба үүрэг (role)
| Role | Юу хийдэг |
|---|---|
| superadmin | Бүх компанийг харна, компани, хувийн тээвэрчин устгана; байгууллага үүсгэнэ; аппын шинэчлэх шаардлагыг тохируулна |
| company_admin | Компанийнхаа бүх зүйл; актыг батлах, буцаах, цуцлах; бүрмөсөн устгах |
| manager | Удирдлага; дүрмийг шалтгаантайгаар override хийж болно (аудитад бичигдэнэ) |
| dispatcher (тээврийн зохицуулагч) | Рейс үүсгэх, батлах, хуваарилах, засвар бүртгэх, зарлал илгээх |
| mechanic (инженер хянагч) | Машин үзэх, батлах, засварын ба хүлээлцэх акт |
| hr | Жолооч, тээвэрчин, мэдэгдэл, тохиргоо; флот, түлш, рейс, tracking, засварыг харахгүй |
| accountant | Зөвхөн харна, мөнгө байхгүй |
| driver | Аппаар ажилладаг |

- Оффисын ажилтанд "өнөөдрийн ажил" жагсаалт хэрэггүй: ердийн цэсээр ажиллаж, role-оор шүүсэн мэдэгдэл авна. "Өнөөдрийн ажил" зөвхөн жолоочийн аппад.
- Зорилтот RBAC (төлөвлөгөө): membership (хэрэглэгч, компани, салбар, role) + `resource.action` эрх, own / branch / company / platform хүрээтэй. Хяналтын дүрэм нь эрхээс тусдаа "gate".
- Олон компанийн бүтэц (multi-tenant): системд одоо эзэмшигч компани ба түүний охин компани гэсэн 2 байгууллага; тест болон давхар компаниуд 2026-10-12-нд устгагдсан.

## Жолоочийн удирдлага
- Жолоочийн хуудас (2026-10-27-ны шинэ загвар): дээд хэсэгт нэг л төлөв (ажиллаж байна / шалгах хүсэлт илгээсэн / бүртгэл дуусаагүй / идэвхгүй / блоклогдсон / хар жагсаалтад). "Ажилд гарахад" мөрөнд 6 шалгалт: ДАН, жолооны үнэмлэх, мэргэшсэн жолооч, хөлсөөр ажиллах гэрээ, тээврийн хөлсний тушаал, машин хүлээлцэх акт ("6-аас N бэлэн"). Табууд: Мэдээлэл, Гэрээ тушаал, Рейс, Бүх зураг. ДАН-аар дахин шалгах, идэвхгүй болгох, хар жагсаалтад нэмэх нь "Бусад" цэсэнд.
- Жагсаалт: дээр 4 тоо (ажиллаж байгаа, бичиг дутуу, үнэмлэх 60 хоногт дуусах, шалгах хүсэлт); 5 шүүлтүүр; нэр, утас, улсын дугаараар хайна; "Зөвхөн анхаарах" товч; эрэмбэлэх (бүртгүүлсэн, шинэчилсэн огноо, төлөв, нэр); утсан дээр карт.
- Төлөвийн дараалал: Хүлээгдэж буй → Ноорог → Зөвшөөрсөн → Татгалзсан → Блоклогдсон → Хар жагсаалт.
- Ноорог жолооч: аппаар бүртгүүлсэн ч ДАН + профайл дутуу. Шийдвэр (2026-10-15): хүчээр батлахгүй; жолооч аппаар ДАН + профайл хийнэ → "Хүлээгдэж буй" → Жолоочид хуудсанд батална. Админ вэбээс жолооч үүсгэдэггүй: бүгд аппаар бүртгүүлдэг.
- Машин шууд хуваарилах: жолоочийн хуудасны "Машин хуваарилах" (бүрдэл бүхэлдээ дагана; хүсэлттэй ижил шалгалт; ДАН-гүй бол татгалзана; `POST /vehicle-request/direct-assign`). Excel-ийн ажлын хүснэгтээр олон жолоочид нэг дор хуваарилж болно (ижил бичлэг: бүрдэл, хүсэлт, аудит, апп мэдэгдэл).
- Хар жагсаалт: `/drivers/blacklist`, хүснэгт `driver_blacklist` (migration 010), 47 мөр (2026-10-14-нд ачаалсан). Хар жагсаалтын хүмүүсийн нэр, РД, утсыг хаана ч хуулахгүй: дипломд зөвхөн функц ба дүрэм орно.
- Туршилтын бүртгэл (2026-10-23): superadmin шалтгаантайгаар өгнө, аудитад бичигдэнэ, ДАН-гүйгээр турших боломж, "ТУРШИЛТ" тэмдэгтэй.
- Жолоочийн тоо (2026-10-28, нэг шалгалт): систем дэх 54 жолоочоос 23 ДАН-аар баталгаажсан, 31 Ноорог (ДАН 2026-10-21–27-нд улсын талаас ажиллаагүй үе давхцсан); нэг чиглэлийн ажлын хүснэгтийн 59 жолоочоос аппад огт бүртгүүлээгүй 41.

## Машин, бүрдэл, засвар
- Машин гэж юуг тоолох (2026-10-20): зөвхөн зүтгүүр (жолоочтой, түлшний сав, GPS-тэй) машинд тоологдоно; чиргүүл, долли бүрдлийн гишүүн, тоог нь тусад нь. Флот: 152 зүтгүүр, 299 чиргүүл, 102 долли.
- Бүрдэл (rig): Зүтгүүр + Чиргүүл 1 + Долли + Чиргүүл 2; 148 зүтгүүр бүрдэлтэй. Тэнхлэгийн бүдүүвч: tractor 6x4 (үндсэн), 4x2, 8x4; trailer 3axle_dual (үндсэн), 3axle_single, 2axle_dual; dolly 2axle_dual, 1axle_dual.
- Жолооч–машины холбоо нэг эх сурвалжтай (2026-10-28): өмнө нь холбоо 5 газар (машины жолооч талбар, бүрдэл, машины хүсэлт, хүлээлцэх акт, ээлж) хадгалагдаж, газар бүр өөрийг нь уншдаг байсан тул апп, админд өөр өөр харагдсан. Шинэ дүрэм: идэвхтэй бүрдэл = цорын ганц үнэн; машин өгөхөд жолоочийн хуучин машин эхэлж чөлөөлөгдөнө; Excel импорт жолооч шилжүүлэхгүй; бүртгэл устгахад ээлж, бүрдэл, машин чөлөөлөгдөнө; машины хуудсанд "Бүрдэл хаах", "Ээлж дуусгах" товч (SQL 024).
- Техникийн үзлэгийн төлөв (2026-10-28 → 10-29): Excel-ээс орсон үзлэгийн огноо хуваарилалтыг хориглож байсан (152 зүтгүүрийн 65, 299 чиргүүлийн 129-ийн огноо өнгөрсөн), ХУР-ыг автоматаар шалгадаггүй (иргэний зөвшөөрөл шаардлагатай) тул бүгд "Хуучирсан" харагддаг байв. Шийдвэр (2026-10-29): машин, чиргүүлийн үзлэгийн төлөв системд огт хэрэггүй — хориглохгүй, анхааруулахгүй, админд харуулахгүй; огноо машины хуудсанд энгийн мэдээлэл болж үлдэнэ; жолоочийн үнэмлэх, ДАН, хар жагсаалт, АТХУБ-ын шалгалт хэвээр.
- Дугуй: Excel-ээс ачаалсан 4,076 дугуй машин дээр (102 долли дээрх орно), 131 актласан; ачаалах SQL бүрт undo скрипт.
- Засвар ба эд анги: `/repairs` (нэг хуудас), эд ангийн бүртгэл, эд ангийн акт (хүлээгдэж буй badge), Үзлэг / Хүлээлцэх акт, машины хуудасны "Эд анги" tab. Актын төрөл: суурилуулах, ашиглалтаас гаргах, солих, дугуй шилжүүлэх; дугаар `ЭА-<он>-0001` компани бүрт; механик эсвэл зохицуулагч бичнэ → company admin батлах/буцаах/цуцлах; нэг эд ангид нэг л хүлээгдэж буй акт; A4 хэвлэх. Эд ангийн төлөв installed / in_stock / decommissioned; дугуйн нийт км машин солиход хадгалагдана. Эд ангийн төрөл: дугуй, эмээл, татуурга, GPS төхөөрөмж, түлш хэмжигч, кабины халаагч г.м.
- Бүрмөсөн устгах: машин, рейс, компани; зөвхөн байгууллагын админ, "УСТГАХ" гэж бичнэ; идэвхтэй бүрдэл эсвэл ээлжтэй бол татгалзана.
- Санал болгосон, сонгоогүй: км/огноогоор service сануулга, сул зогсолт, баталгааны сануулга, эд ангийн нөөц, QR/barcode.

## Рейс ба ажлын самбар
- Рейс (`tasks`) 8 тэмдэгттэй tracking code-той. Рейсийн хуудсанд жолоочийн нээсэн рейсийг шалгах карт, рейсийн зураг, пүүний баримтын бүх мөр, гарын үсэг зурсан баримт хэвлэх, "Пүүний бүртгэл" Excel/CSV, түгжигдсэн рейсийн түгжээ тайлах ([[Жолоочийн апп]]).
- Ажлын самбар (`/dispatch`): рейсийн картууд, "Захиалгатай", "Жолоочтой" төлөв.
- Машин хүсэлт: "өмнөх машин чөлөөлөгдлөө", "жолооч өөр машинаар ээлжтэй" анхааруулга; машин хуваарилах цонхонд улсын дугаараар хайх.
- Жагсаалтууд баганын нэрээр эрэмбэлэгдэнэ (2026-10-29).

## Газрын зураг ба газрын нэрс
- `/tracking`: OpenStreetMap, машины live байршил, жолоочийн зам, рейсийн зам.
- Газрын нэрс (2026-10-28): компанийн НАБТ, ШТС, терминал, боомт, уурхай, зогсоолын нэр гурван газрын зураг (админ, түлшний хяналт, апп) дээр гарна. Нэг жагсаалт: серверийн `map_places` хүснэгт (SQL 026); оффис Тээвэр → Газрууд хуудсанд нэмж, засаж, нууна; төрөл бүр өөрийн дүрс, өнгөтэй; нэр 8-р томруулалтаас; МН/EN/中文; газар бүр радиустай — түлшний хуудсанд GPS цэнэглэлт радиус дотор бол газрын нэр гарна. Эхний 10 газар баримт ба GPS-ээс тогтоогдсон, 2 нь баримтаар шалгагдсан.

## Зарлал ба push мэдэгдэл (2026-10-29)
- Админ вэб → Зарлал: оффисоос бичсэн зарлал жолоочийн утсанд дуут мэдэгдэл болж очно, аппын Зарлал жагсаалтад үлдэнэ.
- Илгээгч: superadmin, company_admin, тээврийн зохицуулагч, HR (нягтлан биш). Хүлээн авагч: Бүгд / Бүх жолооч / Админууд / сонгосон хүмүүс; хувийн тээвэрчин (компанигүй) авахгүй; илгээсэн хүн өөрөө push авахгүй.
- "Утсанд мэдэгдэл илгээх" товчоор push-ыг унтрааж болно; илгээсний дараа хэдэн утсанд очсон, хэд нь аппад нэвтрээгүй, хэд нь очоогүйг харуулна.
- Утас нэвтрэхэд Firebase токеноо серверт өгнө, гарахдаа устгана (`push_tokens`, SQL 025). Түлхүүр серверийн орчны хувьсагчид; түлхүүргүй бол зарлал хадгалагдана, push л явахгүй. iOS одоогоор push-гүй.

## Ачаа хянах холбоос
- Харилцагч `/track/<code>` нээж ачаа хаана явааг харна, нэвтрэлтгүй. Код 8 тэмдэгт (0/O/1/I/L хасагдсан), рейсийн хуудсанд "Холбоос хуулах".
- Харагдах: ачаа, төлөв, хаанаас хаашаа, компанийн нэр ба утас, улсын дугаар, хүргэлт, байршил ба зам (зөвхөн идэвхтэй үед). Харагдахгүй: жолооч, харилцагч, id.
- API `GET /api/v1/public/track/:code`, IP бүрт минутад 30 хүсэлт; МН/EN/中文; хайлтын системд индекслэгдэхгүй. Хязгаар: зам ээлж хаагдах хүртэл хоосон байж болно.

## Анхаарах машинууд (тайлан, 2026-10-27)
- Хяналтын самбар ба тусдаа Excel: трекергүй, түлшний мэдрэгчгүй, GPS 3+ хоног дуугүй, мэдрэгч гэмтэлтэй, 30 хоногт цэнэглэлт илрээгүй, түлш алдагдсан байж болзошгүй, үзлэгт тэнцээгүй гэсэн ангилал. Тоо ба дүн: [[Түлшний хяналт ба GPS]].
